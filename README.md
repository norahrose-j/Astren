# Astren

Astren is a fictional worldbuilding website and interactive encyclopedia that explores a fantasy realm through handcrafted pages on geography, mythology, history, inhabitants, and collection lore. 

## Overview
This repository contains a front-end-only worldbuilding site for the fictional realm of Astren. The website is organized as a set of static pages that present lore, regional information, and visual storytelling using plain HTML, CSS, and JavaScript.

[Visit Astren](https://norahrose-j.github.io/Astren/)


## Project structure
- `index.html` – landing page
- `regions.html` – geographic overview page
- `deities.html` – deity and mythology overview
- `history.html` – historical overview page
- `inhabitants.html` – people and culture overview
- `style.css` – global styling
- `infopages.css` – shared styling for informational pages
- `main.js` – shared site interactions
- `infopages.js` – shared logic for content pages
- `regions/` – regional lore subpages and assets
- `inhabitants/` – society and culture subpages and assets
- `character/` – character-building subpages and assets
- `collection/` – collection pages and assets
- `fonts/` – custom font files
- `images/` – world and artwork assets
